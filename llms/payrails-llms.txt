- [Detach a Tag from a Dispute](https://docs.payrails.com/reference/detachdisputetag.md): Remove a Tag from a Dispute. This operation is idempotent.
- [List Tags](https://docs.payrails.com/reference/listtags.md): Search and list Tags available to the caller's workspace.
- [Create Tag](https://docs.payrails.com/reference/createtag.md): Create a new Tag.
- [Update Tag](https://docs.payrails.com/reference/updatetag.md): Update a Tag's name, color, or description.
- [Delete Tag](https://docs.payrails.com/reference/deletetag.md): Soft-delete a Tag. Deleted tags can no longer be attached to disputes.
- [Bulk Attach Tags to Disputes](https://docs.payrails.com/reference/bulkattachdisputetags.md): Attaches the same set of tags to multiple disputes in a single operation. For single-select tag types, attaching replaces any existing tag of that type on each dispute. For multi-select tag types, tags are added idempotently. Fails fast if any dispute ID or tag ID is invalid.
- [Bulk Replace Dispute Tags by Type](https://docs.payrails.com/reference/bulkreplacedisputetagsbytype.md): Atomically replaces all tags of the specified type on multiple disputes with the provided set. Sending an empty tagIds array removes all tags of that type from every dispute. Tags of other types are not affected. Fails fast if any dispute ID or tag ID is invalid.
- [Replace Dispute Tags by Type](https://docs.payrails.com/reference/replacedisputetagsbytype.md): Atomically replaces all tags of the specified type attached to a dispute with the provided set. Sending an empty tagIds array removes all tags of that type. Tags of other types are not affected.
- [List dispute service runs](https://docs.payrails.com/reference/listdisputeruns.md): List asynchronous runs in the dispute service, scoped to the workspaces you can access. Runs back operations such as a backfill, which pulls disputes and their related payments from the provider into your dispute and payment records. Use the filters to narrow by run type, status, or resolution; results are ordered most-recent first.
- [Get a dispute service run by ID](https://docs.payrails.com/reference/getdisputerun.md): Retrieve a single dispute service run by its ID, including its execution attempts. A run that exists but belongs to a workspace you cannot access returns 404. Use this to inspect the outcome of a backfill, including its window, the disputes and payments it loaded, and any unsupported operations.
- [List Dispute Alert Enrollments](https://docs.payrails.com/reference/listdisputealertenrollments.md): List the pre-chargeback dispute alert enrollments visible in your workspace.
- [Enroll Descriptors for Dispute Alerts](https://docs.payrails.com/reference/enrolldisputealert.md): Enroll one or more merchant descriptors with a pre-chargeback alert program. Runs synchronously and returns once the provider has accepted the enrollment.
- [Search & list Dispute Alerts](https://docs.payrails.com/reference/listdisputealerts.md): Search and list pre-chargeback dispute alerts in your workspace. Use the available filters to narrow results by status, match state, program, and date range.
- [Get Dispute Alert by ID](https://docs.payrails.com/reference/getdisputealert.md): Retrieve a single pre-chargeback dispute alert by its ID.
- [Action a Dispute Alert](https://docs.payrails.com/reference/actiondisputealert.md): Submit the merchant's chosen outcome for a pre-chargeback dispute alert. The outcome is forwarded to the alert provider and the alert is moved to a terminal status. Runs synchronously and returns once the provider has been notified.
- [List Enrollment Descriptors](https://docs.payrails.com/reference/listenrollmentdescriptors.md): List the descriptors associated with a dispute alert enrollment.
- [Add Descriptors to Enrollment](https://docs.payrails.com/reference/adddescriptorstoenrollment.md): Add one or more merchant descriptors to an existing dispute alert enrollment.
- [Unenroll a Descriptor](https://docs.payrails.com/reference/unenrollenrollmentdescriptor.md): Remove a single descriptor from a dispute alert enrollment. Runs synchronously and returns once the unenroll request has been submitted.
- [List Enrollment Events](https://docs.payrails.com/reference/listenrollmentevents.md): List the activity events for a dispute alert enrollment.
- [List Dispute Alert Events](https://docs.payrails.com/reference/listdisputealertevents.md): List the audit timeline events for a pre-chargeback dispute alert, newest first.
